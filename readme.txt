All the files I have written are located under "Assets/_PROJECT". The project is organized by feature and not by file type. For example, all the files specific to the Miner are in the "Miner" folder.
The "Feature" folder contains the features that are very specific to this project, as opposed to the "Shared" folder which contains more versatile features such as a saving system or pathfinding.
The most important folder is this: "Assets/_PROJECT/Features/GridBuildingSystem". It includes all of the building system but also all the buildings.
The other most important folder is: "Assets/_PROJECT/Features/Resources". It contains all the files relative to the resources and recipes.
